# ericishekwene.org

Eric Ishekwene's one-page portfolio: case studies for Coachable, eero (Amazon) and MedCheck, plus experience, process, projects, skills and contact.

Built with React 19, Vite, Tailwind CSS 4, Base UI and Geist. Dark first with a persistent light theme, responsive CSS only, reduced-motion aware.

```bash
npm install
npm run dev     # local dev server
npm run build   # production build to dist/
npm run lint
```

Content lives in `src/content/`, sections in `src/sections/`, shared primitives in `src/components/` (see `src/components/README.md`). Media is pre-optimized in `public/media/` (inventory in `docs/media-manifest.md`).
